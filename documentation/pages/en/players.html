CSV - Additional playlists

Saves to a CSV file the players that have additional playlists assigned, and those playlists.

Downloads a CSV file to the Downloads folder.

Select the category Players and the action “CSV - Additional playlists”. Then click “Start”.

Change - Groups

Assign a group to a player.

Takes input (“Input Prompt”).

Input

  • 1. player name
  • 2. group name
  • Each player at most once.

An example line:

<player name><group name>

Select the category Players and the action “Change - Groups”, click “Input Prompt”, paste the data and save it. Then click “Start”.

Select the category Players and the action “Change - Locations”, click “Input Prompt”, paste the data and save it. Then click “Start”.

Change - Notes

Set the note of a player.

Takes input (“Input Prompt”).

Input

  • 1. player name
  • 2. note (may be empty = the note is deleted; no tab or line break)

    An example line:

    <player name><note>

    Select the category Players and the action “Change - Notes”, click “Input Prompt”, paste the data and save it. Then click “Start”.

    Change - Player Categories

    Set the categories of a player.

    Takes input (“Input Prompt”).

    Input

    • 1. player name
    • 2. and more: category names (any number, they must exist)
    • One line per player.
    • A line with only the player name removes all its categories.

    An example line:

    <player name><category 1><category 2>

    Select the category Players and the action “Change - Player Categories”, click “Input Prompt”, paste the data and save it. Then click “Start”.

    Change - Player Name

    Rename players.

    Takes input (“Input Prompt”).

    Input

    • 1. current player name
    • 2. new name
    • The new name must contain an identifier followed by an underscore: PB, PC, PD or PE + 4 digits (e.g. PB1234_), or RPI + 3 digits (e.g. RPI123_). The identifier of the current name must not change. The new name must not contain quotes, commas, semicolons or whitespace and must not exist yet.

    An example line:

    <current name><new name>_PB1234_

    Select the category Players and the action “Change - Player Name”, click “Input Prompt”, paste the data and save it. Then click “Start”.

    Check player assets

    Check player assets: verifies that the online players have the files they should have according to their group.

    Takes input (“Input Prompt”).

    Input

    • 1. player name (one per line)
    • The input is optional: an empty input checks all the online players.

    An example line:

    <player name>

    Select the category Players and the action “Check player assets”, click “Input Prompt”, paste the data and save it. Then click “Start”.

    Create - Category

    Create new categories.

    Takes input (“Input Prompt”).

    Input

    • 1. new category name (one per line)
    • The name must not exist yet. It must not contain a semicolon, a tab or the characters ě š č ř ž ý á í é ß; writing it without diacritics is recommended.

    An example line:

    <new category name>

    Select the category Players and the action “Create - Category”, click “Input Prompt”, paste the data and save it. Then click “Start”.

    Screenshot - download

    Screenshot: saves an image of what the player is showing right now. It is saved to the DSMediaplay_snapshots folder in Downloads.

    Takes input (“Input Prompt”).

    Input

    • 1. player name (one per line)
    • The player must be online; taking the screenshot can take a few seconds.

    An example line:

    <player name>

    Select the category Players and the action “Screenshot - download”, click “Input Prompt”, paste the data and save it. Then click “Start”.

    Screenshot - view

    Opens the table of the players, the same as the Live-view button: every online player has a Screenshot button that shows the current screenshot. See the page about the table of players.

    Opens a window.

    Select the category Players and the action “Screenshot - view”. Then click “Start”.

    Remove - Additional playlists

    Remove the additional playlists of players.

    Takes input (“Input Prompt”).

    Input

    • 1. player name (one per line; further columns are ignored)
    • Only players that have an additional playlist are processed.

    An example line:

    <player name>

    Select the category Players and the action “Remove - Additional playlists”, click “Input Prompt”, paste the data and save it. Then click “Start”.

    Remove - Unused Categories

    Delete unused categories.

    Takes input (“Input Prompt”).

    Input

    • 1. category name (one per line)
    • Categories whose name starts with "test" are skipped.

    An example line:

    <category name>

    Select the category Players and the action “Remove - Unused Categories”, click “Input Prompt”, paste the data and save it. Then click “Start”.

    Remove All - Unused Categories

    Deletes all the unused categories. The list is shown and confirmed first.

    Takes no input, it is run with “Start”.

    Select the category Players and the action “Remove All - Unused Categories”. Then click “Start”.
