Set Groups to Players

Step 1: Select the group category

1. Open the DSMediaplay control panel.

2. In the dropdown menu "Select category," choose "Players".

3. In the dropdown menu "Select action," choose "Set Groups".

Step 2: Enter group data

1. Click the "Input Prompt" button.

2. Paste the group list for players from your table into the displayed field.

3. Click "Save" to confirm the data.

Step 3: Run the action

1. Return to the main menu of the DSMediaplay control panel.

2. Click the "Start" button to set the groups for the players.
