What the application is for

DSMediaplay_app is a control panel for DSMediaplay customer accounts. Instead of clicking through the web interface, you change the settings of players, groups, playlists, locations and assets in bulk: paste the data from a spreadsheet, or download it to CSV, edit it and paste it back. Two buttons open a live overview of the players.

Getting started

  1. Add a customer account and a login (the + button), enter the password and click “Save Login Details”. The password is checked on the server and stored in the password store of your computer, not in a file.
  2. Select a category and an action.
  3. If the action takes input, click “Input Prompt”, paste the data following the template and save it.
  4. Click “Start”. The log window shows the progress. What cannot be undone (deleting, deploy) is asked about first.

The details are on the Main window page. All the actions are described in the categories above.

Worth remembering

  • The names in the input must match the names on the server exactly (letter case, accents, no spaces at the ends).
  • Try an action that changes something on a test account, or on one record, first.
  • What has been done is not undone. STOP only holds back what has not started yet.
