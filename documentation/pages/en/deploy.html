Sending the content to the players at once.

The actions of this category (the name is exactly as in the application):

  • Deploy - all players
  • Deploy - selected groups

Deploy - all players

Starts a deploy to all the online players of the selected account, in batches. The same as the DEPLOY ALL button. Before it starts, the log window shows the number of players and asks; players without a group and offline players are skipped.

Takes no input, it is run with “Start”.

Select the category Deploy and the action “Deploy - all players”. Then click “Start”.

Deploy - selected groups

Deploy the selected groups: the content is deployed to all online players of these groups.

Takes input (“Input Prompt”).

Input

  • 1. group name (one per line)

    An example line:

    <group name>

    Select the category Deploy and the action “Deploy - selected groups”, click “Input Prompt”, paste the data and save it. Then click “Start”.
