Actions on playlists: their assets, settings and the clean-up of unused ones.

The actions of this category (the name is exactly as in the application):

  • CSV - Playlist Settings
  • CSV - Playlists Details
  • CSV - Unused Playlists
  • Change - Assets to Playlists
  • Change - Playlist settings
  • Create - Playlist
  • Remove - Assets from Playlists
  • Remove - Unused Playlists
  • Remove All - Unused Playlists

CSV - Playlist Settings

Saves the settings of the playlists (the domination interval) to a CSV file, in the form the playlist-settings action takes.

Downloads a CSV file to the Downloads folder.

Select the category Playlists and the action “CSV - Playlist Settings”. Then click “Start”.

CSV - Playlists Details

Saves every playlist and its assets (the files in it) to a CSV file.

Downloads a CSV file to the Downloads folder.

Select the category Playlists and the action “CSV - Playlists Details”. Then click “Start”.

CSV - Unused Playlists

Saves to a CSV file the playlists that no group uses, no player as an additional one and no zone of another playlist.

Downloads a CSV file to the Downloads folder.

Select the category Playlists and the action “CSV - Unused Playlists”. Then click “Start”.

Change - Assets to Playlists

Set the assets of a playlist: the playlist content is replaced by the listed assets in the listed order.

Takes input (“Input Prompt”).

Input

  • 1. playlist name
  • 2. and more: asset names (any number, empty cells are skipped)
  • One line per playlist.

An example line:

<playlist name><asset 1><asset 2><asset 3>

Select the category Playlists and the action “Change - Assets to Playlists”, click “Input Prompt”, paste the data and save it. Then click “Start”.

Change - Playlist settings

Set a playlist: the domination interval.

Takes input (“Input Prompt”).

Input

  • 1. playlist name
  • 2. domination interval (a whole number, e.g. 300; empty = domination off)

    An example line:

    <playlist name>300

    Select the category Playlists and the action “Change - Playlist settings”, click “Input Prompt”, paste the data and save it. Then click “Start”.

    Create - Playlist

    Create new playlists.

    Takes input (“Input Prompt”).

    Input

    • 1. new playlist name (one per line)
    • The name must not exist yet. It must not contain a semicolon, a tab or the characters ě š č ř ž ý á í é ß; writing it without diacritics is recommended.

    An example line:

    <new playlist name>

    Select the category Playlists and the action “Create - Playlist”, click “Input Prompt”, paste the data and save it. Then click “Start”.

    Remove - Assets from Playlists

    Remove assets from a playlist by a keyword.

    Takes input (“Input Prompt”).

    Input

    • 1. playlist name
    • 2. keyword (every asset whose name contains it is removed; case-sensitive)

      An example line:

      <playlist name><keyword>

      Select the category Playlists and the action “Remove - Assets from Playlists”, click “Input Prompt”, paste the data and save it. Then click “Start”.

      Remove - Unused Playlists

      Delete unused playlists.

      Takes input (“Input Prompt”).

      Input

      • 1. playlist name (one per line)
      • Playlists labelled "test" are skipped.

      An example line:

      <playlist name>

      Select the category Playlists and the action “Remove - Unused Playlists”, click “Input Prompt”, paste the data and save it. Then click “Start”.

      Remove All - Unused Playlists

      Deletes all the unused playlists (the ones the unused-playlists CSV lists). The list is shown and confirmed first; playlists labelled “test” are skipped.

      Takes no input, it is run with “Start”.

      Select the category Playlists and the action “Remove All - Unused Playlists”. Then click “Start”.
