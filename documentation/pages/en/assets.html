Actions on assets (files): validity, overviews and the clean-up of unused ones.

The actions of this category (the name is exactly as in the application):

  • CSV - detailed Assets
  • CSV - validity Assets
  • CSV - Unused Assets
  • Change - validity Assets
  • Remove - Unused Assets
  • Remove All - unused Assets

CSV - detailed Assets

Saves the details of all the assets to a CSV file: type, duration, size, resolution, validity period, the playlists that use the asset, and categories.

Downloads a CSV file to the Downloads folder.

Select the category Assets and the action “CSV - detailed Assets”. Then click “Start”.

CSV - validity Assets

Saves the validity of the assets (dates and hours) to a CSV file, in the form the asset-validity action takes.

Downloads a CSV file to the Downloads folder.

Select the category Assets and the action “CSV - validity Assets”. Then click “Start”.

CSV - Unused Assets

Saves to a CSV file the assets that no playlist contains (not even as a logo or in a zone).

Downloads a CSV file to the Downloads folder.

Select the category Assets and the action “CSV - Unused Assets”. Then click “Start”.

Change - validity Assets

Set the validity of an asset.

Takes input (“Input Prompt”).

Input

  • 1. asset name
  • 2. valid from: a date or empty
  • 3. valid to: a date or empty
  • 4. from what hour: a whole hour 0-23 (e.g. 8 or 08:00) or empty
  • 5. until what hour: a whole hour 1-24 (24 or 00:00 = until midnight) or empty
  • Date: DD.MM.YYYY (e.g. 31.12.2026).
  • The hours are used only when at least one date is filled in; with no dates the validity is off.
  • The dates and the hours are checked when the input is loaded; the server takes whole hours only (no minutes).

An example line:

<asset name>01.01.202631.12.202608:0018:00

Select the category Assets and the action “Change - validity Assets”, click “Input Prompt”, paste the data and save it. Then click “Start”.

Remove - Unused Assets

Delete unused assets.

Takes input (“Input Prompt”).

Input

  • 1. asset name (one per line)
  • Assets labelled "test" are skipped.

An example line:

<asset name>

Select the category Assets and the action “Remove - Unused Assets”, click “Input Prompt”, paste the data and save it. Then click “Start”.

Remove All - unused Assets

Deletes all the unused assets. The list is shown and confirmed first; assets labelled “test” are skipped.

Takes no input, it is run with “Start”.

Select the category Assets and the action “Remove All - unused Assets”. Then click “Start”.
