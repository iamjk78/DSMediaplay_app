CSV - Group Settings

Saves the settings of the groups to a CSV file: resolution, orientation, automatic restart and deploy, combining the default playlist, the display schedule and the video player. It has the form the group-parameters action takes.

Downloads a CSV file to the Downloads folder.

Select the category Groups and the action “CSV - Group Settings”. Then click “Start”.

CSV - Identical Groups

Saves to a CSV file the groups that have the same playlists (with the same validity) and the same orientation, that is, groups that could be merged.

Downloads a CSV file to the Downloads folder.

Select the category Groups and the action “CSV - Identical Groups”. Then click “Start”.

CSV - Scheduled Playlists

Saves the groups and their playlists, with the validity (dates, days of the week, times), to a CSV file. It has the form the “playlists of the groups” action takes, so it can be edited and pasted back.

Downloads a CSV file to the Downloads folder.

Select the category Groups and the action “CSV - Scheduled Playlists”. Then click “Start”.

CSV - Unused Groups

Saves to a CSV file the groups that no player belongs to.

Downloads a CSV file to the Downloads folder.

Select the category Groups and the action “CSV - Unused Groups”. Then click “Start”.

Add - Playlists to Group (existing stay)

Add playlists to a group: they are added to the existing ones, which stay.

Takes input (“Input Prompt”).

Input

  • 1. group name
  • 2. and more: any number of blocks of 6 columns (always all 6; leave empty cells empty, keep the tabs):
  • a) playlist name
  • b) valid from: a date or empty
  • c) valid to: a date or empty
  • d) days of the week or empty
  • e) from what time: a time or empty
  • f) until what time: a time or empty
  • One line per group (there is no default playlist column).
  • Date: DD.MM.YYYY (e.g. 31.12.2026).
  • Time: HH:MM (e.g. 08:00); an off time of 00:00 is taken as 23:59, the on time must be earlier than the off time.
  • Days: codes separated by commas: mo = Monday, tu = Tuesday, we = Wednesday, th = Thursday, fr = Friday, sa = Saturday, su = Sunday; or the API numbers 1-7 (1 = Sunday ... 7 = Saturday). Empty = every day.

An example line:

<group name><playlist name>01.01.202631.12.2026mo,tu,we,th,fr08:0018:00

Select the category Groups and the action “Add - Playlists to Group (existing stay)”, click “Input Prompt”, paste the data and save it. Then click “Start”.

Change - Group Name

Rename groups.

Takes input (“Input Prompt”).

Input

  • 1. current group name
  • 2. new name
  • The new name must not contain a space, a comma, a semicolon or quotation marks, must not exist yet and must not be repeated.

An example line:

<current name><new name>

Select the category Groups and the action “Change - Group Name”, click “Input Prompt”, paste the data and save it. Then click “Start”.

Change - Group Playlists (replaces existing)

Set the playlists of a group: the group's playlists are replaced by the listed ones.

Takes input (“Input Prompt”).

Input

  • 1. group name
  • 2. default playlist (no restrictions; may be empty)
  • 3. and more: any number of blocks of 6 columns (always all 6; leave empty cells empty, keep the tabs):
  • a) playlist name
  • b) valid from: a date or empty
  • c) valid to: a date or empty
  • d) days of the week or empty
  • e) from what time: a time or empty
  • f) until what time: a time or empty
  • One line per group.
  • Date: DD.MM.YYYY (e.g. 31.12.2026).
  • Time: HH:MM (e.g. 08:00); an off time of 00:00 is taken as 23:59, the on time must be earlier than the off time.
  • Days: codes separated by commas: mo = Monday, tu = Tuesday, we = Wednesday, th = Thursday, fr = Friday, sa = Saturday, su = Sunday; or the API numbers 1-7 (1 = Sunday ... 7 = Saturday). Empty = every day.

An example line:

<group name><default playlist><playlist name>01.01.202631.12.2026mo,tu,we,th,fr08:0018:00

Select the category Groups and the action “Change - Group Playlists (replaces existing)”, click “Input Prompt”, paste the data and save it. Then click “Start”.

Change - Group settings

Set the parameters of a group.

Takes input (“Input Prompt”).

Input

  • 1. group name
  • 2. resolution (text as in the CSV export, e.g. 1080p)
  • 3. orientation (text as in the CSV export, e.g. landscape)
  • 4. auto restart: time HH:MM, empty = off
  • 5. auto deploy: time HH:MM, empty = off
  • 6. combine the default playlist: true / false
  • 7. play all eligible playlists: true / false
  • 8. LCD on: time HH:MM
  • 9. LCD off: time HH:MM (fill in both 8 and 9, or neither)
  • 10. video player: default / mpv / cvlc
  • Only true, 1 or yes mean yes; anything else (even "ano") means no.
  • One line per group.

An example line:

<group name>1080plandscape03:0004:00truetrue06:0022:00default

Select the category Groups and the action “Change - Group settings”, click “Input Prompt”, paste the data and save it. Then click “Start”.

Create - Group

Create new groups.

Takes input (“Input Prompt”).

Input

  • 1. new group name (one per line)
  • The name must not exist yet. It must not contain a semicolon, a tab or the characters ě š č ř ž ý á í é ß; writing it without diacritics is recommended.

An example line:

<new group name>

Select the category Groups and the action “Create - Group”, click “Input Prompt”, paste the data and save it. Then click “Start”.

      Remove All - Expired Playlists

      Takes out of all the groups the playlists whose validity (a switched-on date restriction) has ended. The log says which playlists were taken out of which group. The playlist itself is not deleted.

      Takes no input, it is run with “Start”.

      Select the category Groups and the action “Remove All - Expired Playlists”. Then click “Start”.

      Remove All - Unused Groups

      Deletes all the groups that no player belongs to. The list is shown and confirmed first.

      Takes no input, it is run with “Start”.

      Select the category Groups and the action “Remove All - Unused Groups”. Then click “Start”.
