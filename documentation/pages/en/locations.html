Actions on locations: the times the displays are switched on and off, renaming, creating and the clean-up.

The actions of this category (the name is exactly as in the application):

  • CSV - ON/OFF Times
  • CSV - Unused Locations
  • Change - LCD ON/OFF Times
  • Create - Locations
  • Rename - Locations
  • Remove - Unused Locations
  • Remove All - Unused Locations

CSV - ON/OFF Times

Saves the times the displays are switched on and off in the locations, by day of the week, to a CSV file, in the form the location-times action takes.

Downloads a CSV file to the Downloads folder.

Select the category Locations and the action “CSV - ON/OFF Times”. Then click “Start”.

CSV - Unused Locations

Saves to a CSV file the locations that no player is in.

Downloads a CSV file to the Downloads folder.

Select the category Locations and the action “CSV - Unused Locations”. Then click “Start”.

Change - LCD ON/OFF Times

Set the on and off times of a location for each day of the week.

Takes input (“Input Prompt”).

Input

  • 1. location name
  • 2. Sunday - on
  • 3. Sunday - off
  • 4. Monday - on
  • 5. Monday - off
  • 6. Tuesday - on
  • 7. Tuesday - off
  • 8. Wednesday - on
  • 9. Wednesday - off
  • 10. Thursday - on
  • 11. Thursday - off
  • 12. Friday - on
  • 13. Friday - off
  • 14. Saturday - on
  • 15. Saturday - off
  • The days start with Sunday, as in the CSV export and in DSMediaplay.
  • Always all 15 columns; an empty cell = nothing is set for that day.
  • Time: HH:MM (e.g. 08:00); an off time of 00:00 is taken as 23:59, the on time must be earlier than the off time.

An example line:

<location name>08:0018:0008:0018:0008:0018:0008:0018:0008:0018:00

Select the category Locations and the action “Change - LCD ON/OFF Times”, click “Input Prompt”, paste the data and save it. Then click “Start”.

Create - Locations

Create new locations.

Takes input (“Input Prompt”).

Input

  • 1. new location name (one per line)
  • The name must not exist yet. It must not contain a semicolon, a tab or the characters ě š č ř ž ý á í é ß; writing it without diacritics is recommended.

An example line:

<new location name>

Select the category Locations and the action “Create - Locations”, click “Input Prompt”, paste the data and save it. Then click “Start”.

Rename - Locations

Rename locations.

Takes input (“Input Prompt”).

Input

  • 1. current location name
  • 2. new name
  • The new name must not contain a space (or other white space) and must not exist yet.

An example line:

<current name><new name>

Select the category Locations and the action “Rename - Locations”, click “Input Prompt”, paste the data and save it. Then click “Start”.

Remove - Unused Locations

Delete unused locations.

Takes input (“Input Prompt”).

Input

  • 1. location name (one per line)
  • Locations labelled "test" are skipped.

An example line:

<location name>

Select the category Locations and the action “Remove - Unused Locations”, click “Input Prompt”, paste the data and save it. Then click “Start”.

Remove All - Unused Locations

Deletes all the locations that no player is in. The list is shown and confirmed first.

Takes no input, it is run with “Start”.

Select the category Locations and the action “Remove All - Unused Locations”. Then click “Start”.
