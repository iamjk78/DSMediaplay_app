It is opened by Live-view, Outages or the action Players → “Screenshot - show”. The data is downloaded from the server and the filters work on it; the lower part shows “Showing N of M” and the time of the last update.

Columns

Name, Status (Online/Offline), Group, Location, Label, Synchronized, Reported, Note, Temperature and Version. The buttons next to “Show columns” show and hide the columns (green is shown, red is hidden); Temperature and Version are hidden by default. Drag the black line between columns to change the width of a column; “Default columns” returns the default widths. The A buttons change the size of the text in the window. The application remembers the size of the window, the columns and the text for every account.

Filters and sorting

  • Under the header there is a filter for every column: text (name, note; letter case and accents do not matter), a choice (status, group, location, label), an age (synchronized, reported) and a temperature. The choice “(all)” switches a filter off.
  • “Reset” clears all the filters.
  • A click on the header of a column sorts by it, a second click reverses the direction. Players that have no value (never reported, no temperature) are always at the end.

Updating

“Refresh” loads the players again (at the earliest 10 seconds after the previous load); a window that is left open updates itself after 10 minutes. Outages always updates the data when it opens.

Screenshot

The “Screenshot” button of an online player shows the current screenshot of its screen in a window of its own (at most 5 windows at a time); the window remembers its size. For an offline player the button is red and cannot be pressed.

Copying text

The text in the fields of the table can be selected with the mouse (a drag selects a part, a double click a word, a triple click the whole field) and copied with the usual shortcut (Cmd+C, Ctrl+C on Windows). The other mouse button (Ctrl+click too on macOS) opens a menu: “Copy” copies the selected text, or the whole field when nothing is selected, and “Copy row” copies the shown columns of the row separated by tabs, so that pasted into a spreadsheet they fall into cells.

Outages

The Outages button opens the table with the filters cleared, the column “Reported” shown, a filter for offline players whose name contains “aktivni” (after the naming of the players), and sorted so that the players with the newest report are at the top.
